# Future Form Holz · Offizielle Manufaktur-Website

Moderne, minimalistische und performante Webpräsenz für **Future Form Holz** (Inhaber Stephan Tautenhahn, Schneeberg im Erzgebirge). Entwickelt mit **Next.js 16 (App Router & Turbopack)**, **Tailwind CSS v4** und **TypeScript**.

---

## 🌟 Highlights & Funktionen

- **Echtes Handwerks-Portfolio:** Integrierte Fotogalerie mit über 370 Originalwerken aus der eigenen Werkstatt.
- **Duale Galerie-Ansicht:** Umschaltbar zwischen dynamischem Masonry-Raster (inkl. Filter-Pills) und thematisch gruppierter Präsentation mit 6 Kategorien:
  1. *Schwibbögen & Lichtkunst* (z. B. Groß-Lichtmonumente 1,20 m – 1,80 m, Acrylglas-Schwibbogen »Haamitland Arzgebirg« mit Schneeberger Bergparade)
  2. *Epoxidharzlampen* (kunstvoll gegossene Leuchtunikate mit faszinierender Tiefenwirkung)
  3. *Gartenmöbel & Holzbau* (Adirondack-Sessel, Parkbänke, Pergolen, Raumspartreppen)
  4. *Personalisierte Unikate* (Firmenwerbeschilder, Lichtenberg-Brandmalerei, Pokale, Gravurbretter)
  5. *Lichterspitzen & Tradition* (Bergmann & Engel, traditionelle Weihnachtspyramiden)
  6. *Werkstatt & Entstehung* (200 × 100 cm Großformat-CNC in Aktion, Sambatreppen-Bau, Handschliff)
- **Vollbild-Lightbox:** Puristischer Vollbildmodus mit Zoom, Gestensteuerung, Tastaturnavigation (`Esc`, `←`, `→`, `+`, `-`) und direktem Anfrage-Link – komplett ohne störende Textüberlagerungen.
- **Smart-LED-Integration:** Volle Unterstützung aller LED-Sorten (RGB, CCT, monochrome & adressierbare Stripes) mit nativer Anbindung an **Home Assistant**, **WLED**, Smartphone-App und Sprachsteuerung.
- **Großformat-CNC:** 200 × 100 cm Portalfräse für nahtlose Werkstücke aus einer Platte.
- **Vollständige Rechtssicherheit:**
  - **AGB (`/agb`):** Abgestimmt auf Kleinserien & Unikate, § 19 UStG Kleinunternehmer, Stripe-Zahlungslinks (inkl. Apple Pay & Klarna), gesetzliches 14-tägiges Widerrufsrecht mit § 312g Abs. 2 Nr. 1 BGB Ausschluss bei individuellen Maßanfertigungen, Mängelhaftung und Eigentumsvorbehalt.
  - **Datenschutzerklärung (`/datenschutz` & `/datenschutze`):** 100 % DSGVO-konform, Vercel Hosting mit abgeschlossenem AVV (Data Processing Addendum nach Art. 28 DSGVO), Stripe Checkout, lokale Schriften via `next/font` (keine Google Fonts Serveranfragen), 0 Tracking-Cookies (kein Cookie-Banner erforderlich).
  - **Impressum (`/impressum`):** Vollständige Anbieterkennzeichnung nach § 5 DDG und § 18 Abs. 2 MStV.
  - **Globaler Footer:** Durchgehend auf allen Seiten eingebunden mit sichtbaren Rechtslinks und Werkstattdaten.

## 🚀 Lokale Entwicklung

```bash
# Abhängigkeiten installieren
npm install

# Entwicklungsserver starten
npm run dev

# Produktionstest & Build
npm run build
npm run start

# Code-Qualitätsprüfung
npm run lint
```

Standardmäßig läuft die Anwendung lokal unter [http://localhost:3000](http://localhost:3000).

## 🛠️ Tech-Stack

- **Framework:** Next.js 16.4.2 (App Router, Turbopack)
- **Sprache:** TypeScript 5
- **Styling:** Tailwind CSS 4
- **Icons:** Lucide React
- **Hosting-Empfehlung:** Vercel (Edge CDN, SSL, automatisches Deployment via Git)
